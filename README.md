# Camera Specs

主要メーカーのミラーレスカメラを、共通の項目で検索できる個人用スペックシートです。

## Features

- メーカー、センサーサイズ、用途による絞り込み
- 機種名・マウントの検索
- PC向け一覧表とスマートフォン向けカード表示
- 各メーカーの公式製品ページへのリンク

## Data

カメラ情報は `data.js` にまとめています。新しい機種は既存のオブジェクトを複製し、同じキーで値を追加してください。連写や動画の最高値は撮影条件によって異なるため、購入判断にはリンク先の公式仕様を確認してください。

## GitHub Pages

`main` ブランチへの更新時に GitHub Actions が自動で公開します。公開先は `https://4k29.github.io/camera/` です。
